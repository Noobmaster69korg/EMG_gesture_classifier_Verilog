# EMG_gesture_classifier_Verilog
This repo's main objective is to store the verilog codes for the baseline emg classifier (IISc DESE), so that people in future who work on this have the baseline model's RTL code rightaway

To understand the shape and dimensions of the CNN model, one can refer to [📄 Detailed Thesis of the Model](./Model_description/summary_of_model.pdf). If you guys want to just have a glance, then [One Table Summary](./Model_description/summary_of_MODEL.png) will suffice.

The vivado XPR file has been included over [Here](./Vivado_Project_File/EMG_imple_in_fpga.xpr). Hopefully you would be able to open thos straightaway in your respective devices. It will reduce a lot of work. Vivado version that I worked on was 2025.1.
